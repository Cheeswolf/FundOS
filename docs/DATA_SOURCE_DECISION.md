# 真实数据源选型决策

## 1. 决策

FundOS 采用两级数据策略：

1. **受控研发与内部模拟**：优先验证 Tushare Pro 接口；
2. **公开生产**：使用获得明确授权的数据供应商，或取得现有供应商对目标用途的书面授权。

选择 Tushare Pro 作为数据验证候选，是因为其官方文档覆盖：

- [公募基金列表](https://tushare.pro/document/1?doc_id=19)，包括场内和场外基金；
- [公募基金净值](https://tushare.pro/document/2?doc_id=119)，包括单位净值、累计净值、复权单位净值和公告日期；
- [交易日历](https://tushare.pro/document/2?doc_id=26)；
- [指数每日指标](https://tushare.pro/document/2?doc_id=128)。

接口积分或调用权限不自动等同于数据再分发授权。因此，Tushare 验证通过也不能自动解除公开展示的授权门槛。

## 2. 数据口径

### 基金净值

优先级为：

1. 复权单位净值 `adj_nav`；
2. 累计净值 `accum_nav`；
3. 单位净值 `unit_nav`。

不得在同一条历史序列中无记录地切换字段。每条记录至少保存：

- 内部资产代码；
- 供应商代码；
- 净值日期；
- 公告日期；
- 原始字段和原始值；
- 标准化后的估值；
- 数据源；
- 获取时间；
- 修订状态。

### 指数

沪深300和中证500的验证候选代码分别为 `000300.SH` 和 `000905.SH`。
中证指数官方编制方案说明指数通过其数据服务渠道发布；正式公开使用前仍需确认目标数据服务的授权条件：

- [沪深300指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000300_Index_Methodology_cn.pdf)
- [中证500相关指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000904_Index_Methodology_cn.pdf)

### 交易日

基金净值日不等于所有底层市场的共同交易日。系统必须同时保存中国交易日历和原始净值日期，组合计算继续使用共同可估值日，不得用前值填充伪造收益。

## 3. 供应商验收项

任何供应商进入 `forward_trial_active` 前必须通过：

- 六类资产覆盖率；
- 至少三年历史深度；
- 日常更新时间与失败补发机制；
- 历史修订识别能力；
- 公告日期可得性；
- 请求频率和批量接口能力；
- 服务可用性与错误语义；
- 数据使用、缓存、展示和再分发权利；
- 费用及续费条件；
- 可导出性，避免供应商锁定。

## 4. 数据质量门槛

每日同步必须检查：

- 主键重复；
- 净值非正数；
- 日期倒序；
- 连续缺失；
- 单日异常变动；
- 公告日期早于净值日期；
- 同一净值日期发生修订；
- 供应商代码或基金状态变化。

硬错误阻断运营周期；可解释的延迟进入告警并等待补发。

## 5. 接入顺序

1. 基金列表和标的筛选；
2. 基金净值与公告日期；
3. 中国交易日历；
4. 指数基准；
5. 汇率与海外交易日历；
6. 数据质量报告；
7. 历史回填；
8. 每日增量同步；
9. 前向模拟激活。

## 6. 当前明确不采用

- 将网页抓取作为唯一生产数据源；
- 将 Alpha Vantage ETF 代理业绩标记为场外基金业绩；
- 忽略公告日期，只按净值日期回填；
- 关闭 TLS 校验；
- 在未确认授权时公开再分发原始数据。
