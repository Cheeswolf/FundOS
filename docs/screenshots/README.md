# FundOS 截图

GitHub 展示计划使用两张不包含敏感信息的 PNG：

1. `dashboard-overview.png`：打开真实数据试用产品的“组合总览”，完整显示产品名称、历史模拟披露、主要指标、净值曲线和资产配置。
2. `agent-research.png`：打开同一产品的“投研观点”，显示 Agent 报告日期、市场状态、摘要、资产观点和证据引用。

建议浏览器宽度不低于 1440 像素。截图前隐藏书签栏、开发者工具、系统通知及任何包含 API Key、用户名或本地绝对路径的内容。

2C 完成后还可补充 `evidence-review.png`，展示不包含敏感内容的证据审核只读视图。
