# FundOS 生产部署检查清单

## 部署前

- [ ] 全部自动化测试通过；
- [ ] 分支覆盖率达到 75% 门槛；
- [ ] 20 年、6 资产性能基准低于 5 秒；
- [ ] CI Docker 镜像构建成功；
- [ ] `.env` 未被 Git 跟踪；
- [ ] `FUNDOS_API_KEY` 使用足够长的随机值；
- [ ] 行情供应商密钥已配置且配额满足需求；
- [ ] Webhook 地址已验证；
- [ ] 使用的数据源具备所需授权；
- [ ] ETF 代理映射与投资说明书一致；
- [ ] 明确展示模拟数据或真实数据标识；
- [ ] 对外页面包含风险提示，不包含收益承诺。

## 数据库

- [ ] SQLite 数据目录使用持久化卷；
- [ ] 仅运行一个写入实例；
- [ ] 已生成可恢复的数据库备份；
- [ ] 备份与生产文件不在同一故障域；
- [ ] 启动后确认 schema version 为 14；
- [ ] 检查产品、组合版本和净值记录数量；
- [ ] 已演练一次恢复到新数据库路径。

## 网络与安全

- [ ] 生产入口启用 HTTPS；
- [ ] 写接口不能绕过 `X-API-Key`；
- [ ] API Key 未出现在浏览器端代码；
- [ ] 管理接口限制在可信网络或网关后；
- [ ] 反向代理配置请求大小和超时限制；
- [ ] 容器以非 root 用户运行；
- [ ] 数据目录权限遵循最小权限原则；
- [ ] 日志不包含密钥、完整凭证或敏感 URL。

## 调度与监控

- [ ] 生产管道安排在行情更新后运行；
- [ ] 调度系统依据进程退出码判断成功或失败；
- [ ] `partial` 和 `failed` 均会触发告警；
- [ ] 告警接收人和升级路径明确；
- [ ] 定期检查 `failed` 告警是否积压；
- [ ] 监控 `/health`；
- [ ] 监控最近一次 `pipeline_runs` 状态；
- [ ] 监控最新行情日期和净值日期。
- [ ] 采集 `/metrics` 并为 5xx 错误率和延迟设置阈值；
- [ ] 如启用 OTLP，确认 Collector 收到 `fundos-api` Span；
- [ ] 日志、告警和链路追踪可以通过 `X-Request-ID` / `X-Trace-ID` 关联。

## 投资治理

- [ ] 风控硬规则不通过时无法发布；
- [ ] 投委会审批人已明确；
- [ ] 每次提案关联已定稿研究报告；
- [ ] 每项研究观点包含证据来源；
- [ ] 调仓理由和被否决方案可追溯；
- [ ] 定期生成收益归因和观点验证；
- [ ] 不启用自动实盘交易；
- [ ] 不对用户作出收益承诺。

## 上线后冒烟检查

```text
GET /health                              → 200
GET /products                            → 至少一个预期产品
GET /products/{id}/versions              → 最新版本为 published
GET /products/{id}/performance           → 净值日期正确
GET /products/{id}/operations            → 非 blocked
GET /pipeline-runs?limit=1               → succeeded
GET /alerts?status=failed                → 无未处理异常
GET /operations/metrics                 → 错误率和延迟正常
GET /metrics                            → Prometheus 文本可采集
GET /dashboard                           → 200
```

## 回滚

1. 停止新写入和生产调度；
2. 保留当前数据库及日志副本；
3. 回退到上一可用镜像；
4. 必要时将数据库恢复到新的文件路径；
5. 启动单实例服务；
6. 执行健康检查和数据一致性检查；
7. 确认后恢复调度。

数据库迁移目前只向前执行。若未来迁移包含不可逆结构变化，必须在部署前提供专用回滚或数据恢复方案。
